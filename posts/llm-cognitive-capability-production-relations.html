从条件映射、智能体生产链到内生需求与社会演化的一个形式化框架

过去两年，人们习惯把大语言模型理解成更会聊天的搜索框、更灵活的办公软件，或者一台正在逼近“通用智能”的机器。这些说法各自捕捉了某个侧面，却都遮住了更有经济后果的变化：LLM 正在把原本依附于特定职业、组织与个人经验的认知操作，转化为可以按需调用、反复组合和低成本复制的能力。真正需要解释的因而不是模型会不会写文章，而是当写作、归纳、翻译、编程、规划乃至部分判断持续降价时，哪些东西会变得更稀缺，谁能控制这些稀缺物，以及由此产生的价值如何重新分配。

这也是整个系统的核心矛盾：认知能力的供给正在迅速扩张，把能力变成可信结果的互补条件却没有同步普及。模型可以在几秒内生成客服回复，但它未必知道订单状态，也不能天然承担退款责任；它可以提出治疗建议，却不自动拥有病历、执业资格与风险承保；它可以生成一款应用，却不因此获得用户、品牌与支付渠道。能力越便宜，数据、流程入口、现实执行权、可信评价、组织协调和责任归属越可能成为新的瓶颈。LLM 重构生产关系，首先不是因为它替代了一切，而是因为它不断改写“什么仍然稀缺”。

经济学把蒸汽机、电力与计算机称为通用目的技术，是因为它们能进入许多下游部门、持续改进，并与行业创新形成互补。1 LLM 也具有这些特征，但又多了一层特殊性：它并不只提供一种固定功能，而是一种可被语言、示例、数据和工具状态即时条件化的通用映射。同一套模型参数，上一刻可以解释概率论，下一刻可以读取合同、调用数据库或扮演虚构人物。它更接近一块可编程的认知材料，而不是一件边界清楚的产品；它的社会作用取决于谁来设定条件、把它接到哪里，以及谁有权把输出变成行动。

需求不是提示词，而是状态差距

从消费者一侧看，prompt 从来不是需求本身。一个人说“帮我写申诉信”，真正想要的可能是退回一笔错误扣款；他说“给我做旅行攻略”，想要的是在预算、时间和不确定性约束下获得一次满意的经历。设消费者当前状态为 \(s\)，期望状态为 \(s^*\)，那么需求可以先写成状态差距 \(d=\Delta(s,s^*)\)。函数 \(\Delta\) 不必只是欧氏距离，它可以同时包含金钱损失、知识缺口、情绪不适、等待时间和身份风险。LLM 的经济价值不在于生成多少字，而在于它能否缩小这个差距。

消费者选择的也不是抽象“智能”，而是一条从 \(s\) 到 \(s'\) 的路径 \(\pi\)。若把模型费、时间、注意力、隐私与出错风险都算进去，其净效用可写为 \(V_j(\pi)=\mathbb E[U_j(s')-U_j(s)]-p_j-\alpha_j T_j-\rho_j R_j-\kappa_j E_j\)。这里的 \(p_j\) 是货币价格，\(T_j\) 是耗时，\(R_j\) 是风险，\(E_j\) 是学习和切换成本；不同消费者对这些代价的权重不同。只有当最优路径满足 \(\max_\pi V_j(\pi)>0\)，采用才会发生。免费但不可信的工具可能输给昂贵而可追责的服务，能力更强的模型也可能输给流程更短的产品。

这一定义解释了为什么看似相同的输出会有完全不同的价值。一份由模型生成的合同摘要，对随手浏览的普通人只节省十分钟，对即将签署并承担巨额责任的公司却可能影响一次重大决策。价值不是文本的固有属性，而是输出进入特定状态转换后产生的边际效用。因此，生产者若只优化基准测试或回答长度，往往会错过消费者真正购买的东西：不是答案，而是更高概率、更低摩擦地抵达某个结果。

娱乐与陪伴又揭示了“结果”概念的边界。角色扮演、互动小说或长期陪伴并没有一个等待完成的单一 \(s^*\)，消费者购买的是过程本身。若互动轨迹为 \(\tau=(s_0,a_0,s_1,a_1,\ldots)\)，其效用更适合写成 \(U_j(\tau)=\sum_{t=0}^{T}\beta^t u_j(s_t,a_t)+B_j(\tau)-Q_j(\tau)\)：即时愉悦之外，\(B_j\) 表示连贯记忆、共同创造和关系积累，\(Q_j\) 则表示重复、失控、情感依赖或时间侵占。这里模型不是替消费者完成任务，而是在每轮回应中与他共同生成可消费的时间。

现实使用也早已越过“工作提效”这一条窄缝。对大规模匿名对话的研究显示，人们既把 ChatGPT 用于写作和工作，也大量用于信息获取、实用指导、学习与个人事务，而且同一批用户会随着使用经验增加而发现新用途。2 这说明需求不是一个预先摆在市场上的固定清单。消费者先接触到能力，才逐渐学会描述自己原本无法表达、或认为不值得解决的状态差距；模型在满足需求的同时，也在帮助需求获得语言。

从条件映射到可交付产物

现在才有必要下潜到模型本身。设输入空间、上下文空间和输出空间分别为 \(\mathcal X,\mathcal C,\mathcal Y\)，参数为 \(\theta\)，基础模型可以写成随机映射 \(M_\theta:(x,c)\mapsto p_\theta(y\mid x,c)\)。它不是一张把问题机械对应到答案的表，而是在给定条件下对可能输出分配概率。为了讨论经济用途，可以再把它压缩为能力向量 \(K_\theta=(k_{文本},k_{代码},k_{视觉},k_{推理},k_{工具},\ldots)\)。这个向量不是模型的完整描述，却足以表示某类生产者眼中的可用能力边界。

prompt 的作用，是在这片能力空间里选择一个局部行为区域；context 则决定模型在行动时“看见哪个世界”。若指令为 \(p_t\)，历史、记忆、业务数据和约束被装配成 \(c_t=C(h_t,m_t,e_t,b_t)\)，实际输出便来自 \(p_\theta(y_t\mid p_t,c_t)\)。在有限上下文预算 \(B\) 下，好的装配器追求的不是塞入最多材料，而是选择 \(c_t^*=\arg\max_{c:\operatorname{Cost}(c)\le B} I(c;Y_t^*)\)，即让上下文与正确下一步之间的相关信息最大。上下文工程因而不是模型外围的装饰，它在决定模型所处的局部现实。

然而，一次映射仍然只能产生一次候选输出。Agent harness 带来的质变，是把模型从文本生成器变成行动策略：\(a_t\sim\pi_\theta(a_t\mid c_t)\)，动作 \(a_t\) 可以是搜索、读取文件、查询库存、执行代码、发起付款或把任务交给另一节点；环境随后按 \(e_{t+1}\sim P(e_{t+1}\mid e_t,a_t)\) 更新。模型不再需要在一次推理中“想出整个产物”，它只需根据新证据选择下一步，并把中间结果写进外部世界。能力由此获得了记忆、手脚和可观测的后果。

持续 loop 增加的是计算深度。若一次“观察—行动—环境更新”合成为 \(G_\theta\)，运行 \(T\) 轮后有 \(e_T=G_\theta^T(e_0)\)。graph 则增加结构：检索节点提供证据，规划节点拆分任务，执行节点修改环境，评审节点把不合格结果送回重做，权限节点限制危险动作。循环让复杂度能够累积，图让错误能够被隔离和纠正。稳定的复杂产物通常不是某次神奇回答，而是许多不完美映射在外部约束下迭代收敛的结果。

至此，一条完整生产链才显现出来：基础模型先提供 \(K_\theta\)，prompt 与 context 选择并定位能力，harness 把输出翻译成可执行动作，loop 与 graph 让动作跨时间协作，最终形成产品或服务 \(z\)；消费者使用 \(z\) 后获得状态变化和效用，行为、评价与交易又形成反馈；反馈暴露新需求，带来新业务、再投资、后训练乃至下一轮基础模型训练。前一轮的产物既是后一轮的消费对象，也是后一轮的训练材料、市场信号和组织基础。

想象一家只有三人的跨境商店。店主并不需要“会写广告的模型”，而是需要把一批库存变成可售商品。系统先读取库存与平台规则，生成多语言页面和图片，提交上架，观察点击与退货原因，再修改定价、文案和受众；遇到合规不确定性时转交人工。最终产物不是某段文字，而是一条持续工作的销售闭环。消费者看到的是商品与服务，店主购买的是库存周转率，平台获得新的供给和交易数据，模型供应商只在其中提供了若干可替换的认知步骤。

近年的产品基础设施变化正沿着这条链发生。OpenAI 在 2025 年发布的 Responses API、内置搜索、文件检索、计算机操作与 Agents SDK，明确把“完成多步任务”而非“生成一段回复”作为开发原语；Anthropic 开放的 Model Context Protocol，则试图把模型连接数据与工具的方式标准化。3 这类变化的重要性不在又多了几个接口，而在产业竞争的重心开始从单次模型调用，转向谁能稳定组织上下文、行动、观测和纠错。

同一能力如何进入不同生产函数

对生产者而言，模型能力从来不独自产生产物。主体 \(i\) 的产出可写为 \(z_i=F_i(K_\theta,H_i,D_i,L_i,R_i)\)：\(H_i\) 是 harness、工作流与评测系统，\(D_i\) 是数据和情境知识，\(L_i\) 是品牌、员工、客户关系、牌照与组织惯例，\(R_i\) 是算力、资金和现实设备。这个式子的意义不在于多列几个变量，而在于拒绝把价值归因于模型一项。相同的 \(K_\theta\) 进入不同的互补资产组合，会产生完全不同的质量、成本和可占有收益。

基础模型训练者的任务，是移动能力前沿：把数据、算力、研究、后训练和安全工程变成新的 \(\theta\)，再把它压缩为下游可调用的 \(K_\theta\)。它们可以通过订阅、API、算力合同和生态锁定收费，也承担巨额固定成本与模型失效风险。其竞争优势来自前沿性能、单位推理成本、开发者生态和资本供给，但这些优势并不天然等于最终消费者价值。模型公司能否攫取剩余，取决于前沿能力是否稀缺、替换成本多高，以及它是否同时控制应用和分发。

LLM 原生创业者面对的是另一种问题：没有模型，这项业务是否仍然成立？可用反事实利润增量 \(\Delta\Pi_i=\Pi_i(K_\theta,H_i,D_i,L_i,R_i)-\Pi_i(K_0,H_i^0,D_i,L_i,R_i)\) 来衡量，其中第二项是没有 LLM 时最接近的可行业务。若一个研究代理能以原成本的几十分之一服务长尾用户，或者一人团队能够连续制作过去需要工作室才能完成的互动内容，那么 \(\Delta\Pi_i\) 很大，业务具有真正的 LLM 原生性；若只是给旧软件加一个聊天框，增量往往很快被竞争抹平。

原生业务的壁垒也不能只写成“用了最强模型”。一旦竞争者可以买到相近的 \(K_\theta\)，差异便取决于谁积累了更好的任务轨迹、评测集、用户关系、工具权限和失败恢复机制。创业者真正设计的是一个复合函数，而非一次 prompt。他必须决定何时让模型自主、何时向人追问、如何验证结果、如何定价风险，以及怎样把每次交付变成下一次交付的数据。模型能力决定可行域，组织闭环决定能否长期留在可行域内。

传统企业则不是从零创造一条链，而是把 \(K_\theta\) 嵌入已有生产函数。若原产出为 \(Y_i=F_i(L_i,R_i,D_i)\)，引入模型后变为 \(Y_i'=F_i(L_i,R_i,D_i,K_\theta,H_i)\)，最直接的收益是 LLM 的边际生产率 \(MP_i^{LLM}=\partial Y_i'/\partial K_\theta\)。更重要的是交叉项：若 \(\partial^2Y_i'/\partial K_\theta\partial D_i>0\) 或 \(\partial^2Y_i'/\partial K_\theta\partial L_i>0\)，专有数据和组织资产越深，模型越有价值。于是老企业看似笨重的遗产，也可能在正确改造后变成新技术的放大器。

经验材料同时提醒我们，不要把“自动化”与“增益”混为一个数字。一项发表于《经济学季刊》的实地研究跟踪了 5172 名客服人员，生成式 AI 助手平均提高了约 14% 的问题解决生产率，收益更多落在经验较少的员工身上，说明模型可以把组织中的优秀做法扩散给新手。4 这里的人没有被简单移除，而是人的单位时间产出与学习曲线发生了变化；企业获得的不是一段生成文本，而是知识传播机制的改变。

Klarna 展示了另一种更接近流程自动化的路径。公司早期宣布 AI 助手承接了大部分客服对话，后续提交给监管机构的 2025 年年报称，它处理了当年 80% 的客服聊天，且消费者满意度没有下降。5 这属于公司自报的运营结果，不等同于独立因果实验，却足以说明：当模型接入订单、政策和升级流程后，传统企业可以重写成本结构。与此同时，身份盗用、争议处理等复杂案例仍需高技能人工，价值由一般回复能力迁往例外判断、同理沟通与责任承担。

普通个人生产者处在另一端。他可以用模型写代码、做视频、翻译课程、经营小店或构造游戏，不再需要先成为一个完整组织才有资格生产。更关键的是，他常常在同一条轨迹里变换角色：先消费模型给出的解释，再修改为作品；把作品发布后成为生产者；给其他作品点赞时成为评价者；转发和推荐时又成为分发者。LLM 降低的不是某一职业的门槛，而是消费、学习、试作、生产和传播之间的转换成本。

因此，不能把主体永久划分成企业和消费者。更合适的表示是角色向量 \(r_i=(r_i^{model},r_i^{app},r_i^{inc},r_i^{consumer},r_i^{creator},r_i^{platform},r_i^{capital})\)，每一维表示主体在某种角色上的投入与控制力。模型公司也做消费者应用，平台也训练模型，创作者既付订阅费又为平台贡献数据，资本方也可能通过云与分发持有基础设施。角色重叠使很多交易不再是一次性的买卖，而是价值、数据和权力的持续交换。

平台与分发方尤其不能被当作中性管道。它们决定哪些 LLM 产物能被看见、谁可以接入支付和用户身份、哪种交互会获得推荐，以及反馈数据回到谁手中。生成成本下降后，内容和应用供给可能爆炸，消费者的注意力却没有同比增长，可信筛选反而更稀缺。平台因而既收取交易租，也塑造需求函数：排序、默认入口和审核规则会改变消费者遇见什么、相信什么，甚至改变生产者值得生产什么。

资本方提供的是跨期选择权。训练前沿模型需要承担高固定成本，垂直创业需要在需求尚未清晰时补齐数据和流程，传统企业改造又常遇到短期费用先升、组织收益后到的“生产率 J 曲线”。资本决定哪些能力方向得到算力、哪些互补资产被并购、哪些亏损可以换取市场学习。它并非只在系统外部下注；通过回报期限、估值方法和治理权，资本会把整个生态推向快速替代劳动、长期能力建设或封闭式平台等不同路径。

把这些关系放在一张网络中，可以定义四类有向流：主体 \(u\) 向 \(v\) 提供能力流 \(C_{uv}\)，交付产品流 \(Z_{uv}\)，获得反向货币流 \(M_{vu}\)，同时双方交换信息流 \(I_{uv}\) 与 \(I_{vu}\)。一次普通的聊天订阅就包含全部四项：模型公司给用户能力与产品，用户支付金钱，也用问题、停留、评价和纠错提供信息。若用户再把产物发布到平台，原来终止于消费的边，立即延伸为新的生产和分发边。

四种流通常并不对称。货币可能支付给应用商，能力来自另一家模型公司，用户反馈由平台掌握，风险却由使用者或一线员工承担。拥有最多信息回流的主体可以更快改进产品，拥有默认分发入口的主体可以压低上游议价，拥有执行责任的主体则不能像纯接口商那样轻易替换。所谓多方博弈，实质上就是各方争夺这些流的定价权、观测权、转移成本与责任边界；产品竞争只是这场争夺的可见表面。

能力商品化之后，价值向哪里迁移

由此可以提出一个核心命题：当某种能力被 LLM 商品化时，价值会向仍然稀缺的互补变量迁移。设某项服务价值为 \(V=G(K,Q)\)，其中 \(K\) 是可采购的模型能力，\(Q\) 汇总专有数据、流程接入、信任、品牌、分发和责任能力。若相近模型增多使 \(K\) 的价格 \(p_K\) 下跌，单纯转售 \(K\) 的利润空间会被竞争压缩；但如果生产函数具有互补性 \(\partial^2G/\partial K\partial Q>0\)，更便宜、更强的 \(K\) 反而提高 \(Q\) 的边际产出。能力普及并不让价值消失，而是改变价值落点。

这个结论可以从一个极简利润问题看得更清楚。生产者选择 \(K,Q\) 最大化 \(\Pi=G(K,Q)-p_KK-p_QQ\)，内点最优满足 \(G_K=p_K\) 与 \(G_Q=p_Q\)。在常规凹性条件下，当 \(p_K\) 因模型竞争下降，最优 \(K^*\) 上升；若 \(G_{KQ}>0\)，则原最优点附近的 \(G_Q\) 随 \(K\) 增加而上升，生产者会继续购买或建设更多 \(Q\)，直至新的 \(G_Q=p_Q\)。因此，模型降价不仅削弱模型转售租，还会诱发对互补资产的投资。谁事先控制了稀缺的 \(Q\)，谁就可能吸收由廉价智能释放的更大一部分剩余。

不同场景中的 \(Q\) 并不相同。医疗里的稀缺物是高质量病历、临床验证、执业责任与患者信任；企业软件里是工作流入口、权限体系和迁移成本；娱乐里是角色 IP、持续记忆、社群与注意力；个人生产里则可能是独特经验、审美判断和稳定受众。把“数据是新石油”当成统一答案同样会误导：没有任务语境、更新机制与使用权的数据可能毫无价值，而一个可信品牌或一次现实履约能力，反而比百万条文本更难复制。

DeepSeek-R1 在 2025 年公开模型权重和蒸馏模型，是能力商品化的一次鲜明演示：某些原本只能从少数闭源服务获得的推理能力，突然可以被更多开发者部署、改造和比较。6 但这并不证明基础模型层会趋近于零价值。前沿训练、算力效率、安全与多模态能力仍可能高度集中；商品化也总是按任务发生，而不是整个 \(K_\theta\) 同时变成同质品。更准确的判断是：每当某个能力分量 \(k_m\) 变得可替换，围绕它的租金就重新寻找尚未可替换的邻近环节。

为了比较不同主体从模型中获得的放大效应，可以定义 LLM 杠杆率 \(\Lambda_i=(V_i^{LLM}-V_i^0)/(C_i^{model}+C_i^{adapt})\)。分子是采用 LLM 相对可行反事实所创造的新增价值，分母不仅包括 token、订阅和算力费，也包括数据清洗、流程改造、评测、监督与风险成本。对企业，分子可以用 \(\Delta\Pi_i\)；对个人，则可用折算后的时间、收入或主观效用。高杠杆并不等于多调用模型，一个精简但深度嵌入的流程可能比海量低价值生成拥有更高的 \(\Lambda_i\)。

这个指标也揭示了竞争中的一个常见错觉。模型降价会减少 \(C_i^{model}\)，但当所有对手都能获得同样能力时，产品价格和分子 \(V_i^{LLM}-V_i^0\) 也可能一起下降；为了保持质量，\(C_i^{adapt}\) 还可能上升。长期优势来自让模型与难复制的互补资产产生更强交叉效应，而不是把调用量当成壁垒。所谓“AI 公司”与“非 AI 公司”的分界最终会失去意义，真正的分界将是哪些主体能把廉价认知能力转化为独特、可信并可持续反馈的状态变化。

一个会制造新需求的动力系统

到这里仍把需求视为外生给定，就会漏掉 LLM 最深的反馈。令 \(D_t\) 表示时刻 \(t\) 的需求分布，\(Z_t\) 表示市场上可见的产品集合，\(I_t\) 表示消费者从使用、广告与社会传播中获得的信息，\(S_t\) 表示收入、规范、制度和同伴效应，那么下一期需求可写为 \(D_{t+1}=\Phi(D_t,Z_t,I_t,S_t)\)。产品不仅响应 \(D_t\)，还通过展示“原来这件事可以被做”改变 \(I_t\)，进而重塑 \(D_{t+1}\)。需求由系统内部生成，生产和消费因此不再是单向关系。

在模型普及之前，一个普通人可能不会产生“每天与私人苏格拉底式导师讨论阅读”的有效需求，因为购买人类导师过于昂贵；互动角色能够长期记忆后，人们才会形成对连续虚构关系的偏好；代码代理降低试作成本后，不会编程的人才开始认真想象自己的小工具。这里并非广告凭空制造欲望，而是可行集合扩大后，消费者通过试用发现了新的 \(s^*\)。随着状态差距获得命名，过去潜伏的愿望才变成可观测、可支付、可继续优化的需求。

反馈随后回到生产端。用户的任务、修改、放弃、投诉和付费选择构成信息流，生产者据此改写 prompt、context、graph 和界面；成功轨迹进入评测或在合规条件下进入后训练数据，利润则支持更多算力、人才和分发。可以把能力更新粗略写成 \(K_{t+1}=K_t+\eta R_t+\mu I_t^{train}-\delta K_t\)：研发投资 \(R_t\) 和可用训练信息 \(I_t^{train}\) 推动能力，技术折旧与任务迁移由 \(\delta K_t\) 表示。需求越强，回流越多，某些能力方向就越快改进。

但反馈回路并不天然服务社会福利。平台会优先收集容易量化的点击而非长期满意，企业可能把成本节省当成唯一奖励，模型训练者也可能因付费客户集中而过度优化少数语言和职业。娱乐中的情感黏性尤其说明这一点：更长互动既可能代表真实陪伴，也可能代表依赖。OpenAI 与 MIT Media Lab 的一项研究发现，情感使用与福祉之间的关系高度依赖使用方式和个体差异，并明确警告不能把所有相关性解释为因果。7 因而 \(I_t\) 是带选择偏差的信号，不是社会偏好的无噪声测量。

多方主体会围绕这条回路选择策略。模型商决定能力、价格与开放程度，创业者决定依赖一家还是多模型路由，传统企业决定自动化边界，平台决定排名和抽成，资本决定补贴多久，消费者则以采用、退出、评价和二次创作回应。若用 \(\sigma_i\) 表示主体策略，阶段性均衡满足 \(\sigma_i^*\in\arg\max_{\sigma_i}J_i(\sigma_i,\sigma_{-i};X_t)\)。但这是移动的均衡：任何一方的成功都会改变数据、价格、预期和下一轮能力，使原来的最优策略失效。

例如，应用商最初可能因最强模型取得领先；用户增长带来任务数据和品牌，随后它为降低成本切换到更便宜的模型；模型商为保住信息回流，又推出自有应用或收购分发；平台担心被绕过，则限制接口或扶持另一模型。Capability、Product、Money、Information 四种流不断改道。不能只看某一期收入判断最终赢家，因为一方此刻让利，可能是在购买下一期的训练信号、默认入口或转换成本。

从企业变化到生产关系变化

若要描述整个社会的演化，可以把时刻 \(t\) 的状态压缩为 \(X_t=(K_t,P_t,D_t,A_t,W_t)\)。其中 \(K_t\) 是可用模型能力及其成本，\(P_t\) 是产品、流程和 agent graph 的集合，\(D_t\) 是需求分布，\(A_t\) 是主体角色、资产与连接结构，\(W_t\) 则记录收入、福利、权力和风险的分布。系统按照 \(X_{t+1}=\mathcal F(X_t;\Omega_t)\) 演化，\(\Omega_t\) 包含监管、能源、地缘政治和技术突破等外生冲击。这个表达没有假装能够精确预测未来，却迫使我们同时追踪能力、组织和分配。

劳动变化首先发生在任务而非职业层面。模型接管一部分可描述、可验证的任务，会产生替代效应；成本下降扩大产出，又会提高未自动化任务的需求；新产品和新责任还会创造过去不存在的任务。Acemoglu 与 Restrepo 的任务框架把这三股力量分别称为替代、生产率与复职效应，并指出总产出上升并不保证劳动收入份额同步上升。8 对 LLM 而言，关键变量不是“一个岗位能否被 AI 做”，而是任务如何被重新切分、剩余判断权归谁、效率收益由谁获得。

现实数据尚未给出一条单调路径。Anthropic 的经济指数曾观察到消费者端自动化占比上升，随后 2025 年 11 月的样本里协作增强又重新超过自动化；企业 API 使用则持续更偏自动化。9 这不是互相矛盾，而是说明用途、界面、信任与责任共同决定自主程度。能力提升可能让人愿意完全委托，也可能让熟练用户把模型当成更深入的思考伙伴。同一技术既能缩短组织链条，也能扩大一个人可掌控的项目规模。

生产关系的变化因此集中在控制权上：谁有权设定目标和评价函数，谁拥有上下文与反馈，谁能批准现实行动，谁承担失败成本，谁又能把效率增益变成收入。若少数模型与平台同时控制能力、分发和行为数据，\(A_t\) 会向中心化演化，个人虽获得强工具，却可能失去议价和迁移能力；若开放模型、互操作协议与数据可携带性降低切换成本，能力层会更模块化，价值更可能流向垂直组织、社区和个人品牌。两种路径都与“模型更聪明”相容，差别来自制度与资产结构。

社会福利也不能直接用总生成量衡量。可以写成 \(W_t=\sum_j\omega_j V_{j,t}-E_t^{risk}-E_t^{power}\)，其中 \(\omega_j\) 反映不同群体效用的社会权重，\(E_t^{risk}\) 包含错误、隐私、安全和依赖等外部成本，\(E_t^{power}\) 则表示市场支配与信息控制造成的损失。若廉价内容淹没有效信息、自动化收益只进入资本回报，或者高风险决定缺乏申诉，生产率增长仍可能伴随福利分化。技术给出可能性集合，产权、竞争、劳动协商和公共治理决定集合中的哪一点被实现。

未来最可能出现的不是一种整齐终局，而是多个层次同时演化。前沿模型或许因算力和研究规模保持集中，成熟能力却通过开源、蒸馏和价格竞争扩散；大型企业把 agent graph 嵌入核心流程，个人也用同类能力经营微型组织；平台一边降低创作门槛，一边因注意力与信任稀缺而强化筛选权。中心化与去中心化、替代与增强、商品化与再稀缺化会反复交替，每一次能力突破都把竞争推向新的互补变量。

因此，判断一个主体在 LLM 时代的位置，不应只问他有没有模型，而应问四件事如何连成闭环：他替谁缩小了什么状态差距，他控制哪些不可轻易复制的互补资产，他能否获得真实结果的反馈，以及效率收益和失败责任怎样分配。消费者可能在下一刻成为生产者，生产者也依赖消费者提供评价与数据；平台既组织交易又塑造偏好；资本既放大创新也选择演化方向。所谓新的生产关系，正是在这些重叠角色和不对称流动中形成。

LLM 因而不只是下一代软件。更准确地说，它是一种让认知生产能力持续商品化的基础设施：先把少数人的技巧变成许多人可调用的能力，再把原本不值得完成的任务变成产品，把新产品变成新习惯和新需求，最后用需求与反馈推动下一轮能力建设。它不会自动带来某种预定社会，却会持续移动稀缺性的边界。理解这套系统的关键，不是预测模型终将无所不能，而是追踪每一种能力变便宜之后，价值、责任与权力究竟迁往了哪里。
